# Smart Flight

Works offline on board the plane!

Sit near the window, turn on GPS, and observe how many satellites your device can see. The more satellites you receive, the closer you may be to getting a GPS fix and being able to determine your current position during the flight.

The app is designed to work without an internet connection, making it useful for observing GPS and flight information while flying.

## AI-powered rewrite

This application is a complete rewrite of the original **Smart Flight** application, rebuilt from scratch using modern Android technologies and Jetpack Compose.

The original application is available here:

[Original Smart Flight repository](https://github.com/NieKam/smart-flight/tree/main)

The rewrite is being developed with the help of AI coding agents as an experiment in AI-assisted software development.

## Goals

* Modernize the original application using Jetpack Compose
* Preserve the core functionality of the original app
* Improve the architecture and maintainability
* Explore AI agents as a software development team
* Build and validate the application automatically using GitHub Actions
